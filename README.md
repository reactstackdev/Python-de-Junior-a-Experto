# Python de Junior a Experto

Repositorio de aprendizaje progresivo de Python con objetivo profesional de **Python Backend Developer**.

Stack objetivo: `Python` · `FastAPI` · `PostgreSQL` · `Docker`

---

## Fase 1 — Fundamentos

Sintaxis, tipos de datos, control de flujo, programación orientada a objetos, módulos, excepciones, ficheros y entornos virtuales.

### Contenido

| Día | Tema |
|-----|------|
| 01 | Tipos básicos, listas y diccionarios |
| 02 | Funciones, bucles y condicionales |
| 03 | Clases y OOP — `class`, `__init__`, `self`, métodos |
| 04 | OOP Avanzado — `__str__`, herencia, encapsulación |
| 05 | Módulos y paquetes — `import`, `from...import`, `__init__.py` |
| 06 | Excepciones — `try/except/finally`, `raise` |
| 07 | Ficheros — lectura/escritura `.txt` y `.json` |
| 08 | Entornos virtuales — `venv`, `pip`, `requirements.txt` |
| 09 | OOP Complementos — `@property`, `@classmethod`, `@staticmethod` |

### Reglas de trabajo

- El código lo escribe el desarrollador, nunca la IA
- La IA se usa para explicar errores, proponer ejercicios y hacer code review
- Cada ejercicio tiene su enunciado al principio del fichero
- Cada método retorna un valor — nunca imprime dentro
